# Tetris

A self-contained HTML5 Tetris implementation.

## Features

- 10×20 playfield
- Seven-piece bag randomizer
- Ghost piece
- Hold piece
- Next queue
- Soft drop and hard drop
- Rotation with wall kicks
- Level, line and score progression
- Persistent local high score
- Pause / resume
- Responsive desktop and mobile layout
- No framework, build step or external dependency

## Controls

| Key | Action |
|---|---|
| ← / → | Move |
| ↓ | Soft drop |
| ↑ | Rotate |
| Space | Hard drop |
| C / Shift | Hold |
| P | Pause |

Open index.html directly or serve the repository with any static web server.
